# 📝 Journaling App

This is a fullstack journaling app built with **Next.js** and **MongoDB**. It allows users to create, read, update, and delete journal entries, including mood tracking and category choices.

## 🚀 Features

- Add new journal entries with mood and role
- View all entries in a list
- Edit and delete entries
- Store data in MongoDB

## 🔧 Tech Stack

- Next.js
- React
- MongoDB (via Mongoose)
- Tailwind CSS

## 🛠️ Getting Started

1. Clone the repository  
2. Install dependencies with `npm install`  
3. Add your MongoDB URI to `.env.local` like this:
MONGODB_URI=your-mongodb-uri

Start the development server:
 npm run dev  


Visit http://localhost:3000 to view the app.

📦 Deployment
Deploy to Vercel

Set your MONGODB_URI in the Vercel dashboard under Environment Variables
